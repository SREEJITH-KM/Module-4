## DICTIONARY - SIZE OF DICTIONARY

---

### AIM  
Write a Python code to demonstrate a dictionary with multiple inputs in a key.

---

### ALGORITHM

Initialize an Empty Dictionary:
Create an empty dictionary to store key-value pairs.

Define Input Variables:
Identify the variables that will form the key. For example, x, y, and z.

Formulate the Key:
Combine the input variables into a tuple to serve as a unique key. This allows multiple inputs to be associated with a single key.

Compute the Value:
Perform the necessary computation or assign a value that corresponds to the key.

Store the Key-Value Pair:
Insert the tuple (key) and its corresponding value into the dictionary.

Repeat for Additional Inputs:
For each new set of inputs, repeat steps 2 to 5 to add more key-value pairs to the dictionary.

Access Values:
Retrieve values by referencing the tuple key in the dictionary.
